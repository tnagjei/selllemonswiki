# src/data
- 用途：存放静态网站的基础配置、游戏元数据以及各指南页面呈现的具体事实/社区反馈数据。
- 关键入口：`config.ts` (站点基础 TDK、主题、部署路径配置)
- 边界/依赖：为 `src/pages/` 下的页面提供直接的数据导入和模板变量注入。
> 一旦本目录内容变化，请更新本文件

## Files
- config.ts：站点全局配置，定义品牌主色、允许的路由 slug、已完成地图/工具页和基本 SEO 关键词等。
- game.ts：游戏相关的固定元数据（如 rootPlaceId、开发团队名称等）。
- reported-guides.ts：页面正文内容所需的具体事实列表，区分为官方已验证和社区反馈。
