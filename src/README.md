# src
- 用途：存储网站的核心源代码，包括页面、组件、布局、数据模型和内容数据。
- 关键入口：`src/pages/index.astro` (首页)、`src/data/config.ts` (站点配置)
- 边界/依赖：外部依赖来自 `package.json`，构建输出为 `dist/` 静态目录。
> 一旦本目录内容变化，请更新本文件

## Files
- components/：存放通用且可复用的 UI 组件（如导航头、页脚、关联文章等）。
- content/：包含独立于布局和逻辑的静态网页内容数据。
- data/：定义基础数据结构、全局站点配置以及游戏相关的数据详情。
- layouts/：页面模板布局文件，负责整个网站的 HTML 骨架（包括 Meta TDK、资源引入等）。
- lib/：封装全局通用工具函数（如 SEO 结构、数据分析和页面跳转控制等）。
- pages/：Astro 路由目录，每一个文件对应网站的一个实际访问页面。
- styles/：网站的全局 CSS 样式设计定义。
